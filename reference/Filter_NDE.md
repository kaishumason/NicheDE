# Filter_NDE

This function filters a niche-DE object to only include specific
observations

## Usage

``` r
Filter_NDE(object, cell_names)
```

## Arguments

- object:

  A niche-DE object

- cell_names:

  Cell names of observations that should be kept

## Value

A niche-DE object that only includes the specified cells. We recommend
using this function after calculating the effective niche on the whole
dataset
